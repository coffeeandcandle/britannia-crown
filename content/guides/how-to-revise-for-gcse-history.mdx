GCSE history asks for knowledge, but marks come from using it to explain and argue. Revision should include both.

<Callout title="In a nutshell">

- Build **timelines and summaries** for each topic.
- Practise **question types** from past papers.
- Plan and write **timed essays**.

</Callout>

## Know the course

Check which topics, periods and exam board your child is studying, and the question types in each paper. Make a revision checklist from the specification.

## Build knowledge

Create one-page summaries for each topic with key dates, people, events, causes and consequences. Use timelines and diagrams to show how events link.

## Learn the question types

History papers include questions on sources, interpretations, narrative accounts and extended essays. Learn what each question asks and how marks are awarded.

## Sources and interpretations

For sources, consider content, origin and purpose. For interpretations, identify the argument and compare it with other views, supporting with knowledge.

## Essays

Start with a plan: argument, key points, evidence and conclusion. Practise writing under timed conditions, then compare with mark schemes. Use clear paragraphs.

## Memory

Test yourself with flashcards, quizzes and by explaining topics aloud. Revisit topics regularly.

## Past papers

Use past papers to practise timing and technique. See [how to use past papers](/guides/how-to-use-past-papers).

<Cta>

A history tutor can help with essay structure and exam technique.

</Cta>
